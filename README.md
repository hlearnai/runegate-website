# Runegate website

The website for **Runegate: The Last Portal**. Plain HTML and CSS, no build step.

- `index.html` - the page
- `style.css` - the look
- `stars.js` - the twinkling star background
- `404.html` - page shown for wrong links
- `favicon.svg` - tab icon

Hosted on Cloudflare Pages. Every push to `main` goes live automatically.
Cloudflare settings: Framework preset **None**, build command **empty**, output directory **/**.
